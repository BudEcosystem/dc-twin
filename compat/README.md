# Compatibility harnesses

Each harness drives the twin with a real, unmodified client of a protocol, the way a stack would
([16 — Oracles per adapter](../docs/spec/16-testing.md#oracles-per-adapter)). Results are in
[docs/implementation.md](../docs/implementation.md).
